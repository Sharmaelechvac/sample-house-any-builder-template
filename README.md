# Sample House · Any Builder (Template)

Reusable sample house site template for any builder, showing a planned and photographed house for Sharma Electric & HVAC.

- Live site: https://sample.sharma-crew.workers.dev
- Worker name: `sample`
- Deploy: From this folder: `npx wrangler deploy`

Photos and other binary files are not in this repo (the upload path is text-only). See `MANIFEST.md` for each skipped file, its size, and where it lives on the box.
